Function decompile 

Source 
pub fn decompile<'a>(
    idb: &'a IDB,
    func: &Function<'a>,
) -> Result<CFunction<'a>, HaruspexError>
Expand description

Decompiles Function func in IDB idb.

Each call is a full decompilation, so callers that need the result more than once should keep the returned CFunction rather than call this again.

§Errors

Returns HaruspexError::Decompile if func can’t be decompiled, which doesn’t affect other functions, or HaruspexError::LicenseUnavailable or HaruspexError::DecompilerUnavailable if no function can be decompiled.
